# SWITCH UP Design Projects

Progetti grafici e creativi gestiti tramite Claude + ChatGPT

## Struttura
- /brand - Linee guida brand, colori, font
- /projects - Progetti singoli (logos, mockup, etc)
- /assets - Asset generici (icone, pattern, etc)
- /archive - Versioni precedenti

## Workflow
1. Progetto su GitHub
2. Claude coordina lo sviluppo
3. ChatGPT genera i visual via Copilot
4. Risultati sincronizzati qui
